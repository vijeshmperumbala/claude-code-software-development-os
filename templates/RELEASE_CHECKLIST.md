# Release Readiness Checklist

- [ ] Scope approved and diff reviewed
- [ ] Build passes
- [ ] Required tests pass
- [ ] Security/dependency findings triaged
- [ ] Configuration and secrets reviewed
- [ ] Database migration and recovery plan reviewed
- [ ] Monitoring, alerts and health checks verified
- [ ] Rollback/recovery plan tested or documented
- [ ] Documentation and release notes updated
- [ ] Open risks documented and accepted by authorized owner
- [ ] Human release approval recorded

This checklist assesses readiness; it does not authorize or perform deployment by itself.
