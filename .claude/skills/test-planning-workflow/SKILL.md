# Test plan workflow

Map acceptance criteria to unit, integration, contract, E2E, security, accessibility, device, performance and recovery checks as applicable. Identify fixtures, test data privacy, test environment, flakiness risks, commands, expected outcomes, ownership, and exit criteria. Explicitly mark checks that cannot be automated or cannot be run in the current environment.
