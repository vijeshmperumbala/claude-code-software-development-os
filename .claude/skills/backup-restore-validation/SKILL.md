# Backup and Restore Validation Skill

1. Identify data stores, backup schedule/retention, encryption, ownership, and restore dependencies.
2. Ask for or record target RPO/RTO; do not invent objectives.
3. Review backup integrity, version compatibility, access control, and recovery runbook.
4. Plan restore exercises in an isolated environment with synthetic or approved data.
5. Verify data integrity, application health, permissions, and measured recovery duration.
6. Record gaps and evidence. Never overwrite production or execute destructive recovery without explicit approval.
