# Architecture review

Inspect module boundaries, dependency direction, data ownership, integration contracts, failure modes, security boundaries, deployment model, scalability constraints, testability and operational complexity. Use repository evidence and compare alternatives against requirements. Produce an ADR-style recommendation and list trade-offs. Do not force microservices, a framework, or a rewrite without evidence.
