# Incident readiness workflow

Review service ownership, alerting, logs/metrics/traces, runbooks, incident severity, escalation, rollback, backups/restore drills, RPO/RTO, dependency outages, communication and post-incident learning. Do not change production settings or trigger incidents. Return gaps and tabletop test recommendations.
