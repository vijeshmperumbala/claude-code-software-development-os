# Device and UX Quality Rules

- Establish supported platforms and minimum versions from product requirements; do not assume universal support.
- Test responsive layouts, keyboard/focus, touch target usability, zoom/text scaling, loading/empty/error states and network interruption where applicable.
- Use WCAG 2.2 AA as a target where applicable unless the product or applicable standard specifies otherwise; report scope and exceptions.
- Measure startup/rendering/interaction performance on representative devices when device performance is a requirement.
