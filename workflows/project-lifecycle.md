# Engineering Lifecycle

1. Discover: inspect repository and clarify outcome/constraints.
2. Define: approved requirements, acceptance criteria, risks and target platforms.
3. Design: architecture/data/API/UX/security decisions, ADRs and verification plan.
4. Implement: small reviewed changes, tests, docs and observability.
5. Verify: deterministic tests, independent audits, compatibility and measured performance as applicable.
6. Release assess: deployment, migration, rollback, recovery, monitoring and support evidence.
7. Learn: record defects, incidents, metrics and architectural decisions.

At each stage, report evidence and unresolved assumptions. Approval gates are decision points, not ceremonial documents.
