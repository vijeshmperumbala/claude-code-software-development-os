# Security Remediation Workflow

1. Validate scope and authorization.
2. Triage evidence, severity, confidence, affected assets and exposure.
3. Reproduce safely in a controlled environment when possible.
4. Approve a minimal remediation plan and regression test.
5. Implement through an authorized write-enabled workflow.
6. Retest independently; confirm no regression.
7. Record residual risk, affected versions, and release/notification decisions for human review.
