# Production Release Workflow (Assessment Only)

- Verify approved scope and a clean/understood git diff.
- Verify build, tests, security/dependency checks, config, secrets handling, migrations, backups, health checks, observability, rollback and support docs.
- Confirm migrations are backward-compatible or have a tested rollback/recovery plan.
- Identify release blockers and unresolved risks.
- Present the release evidence and request explicit human approval.
- This workflow does not deploy, publish, or change production resources.
