# Backup, Restore, and Recovery Validation

1. Inventory data stores, backup mechanisms, retention, encryption, restore dependencies, and recovery owners.
2. Record target RPO/RTO only when supplied or approved; label unknown objectives as unknown.
3. Review runbooks and backup integrity checks.
4. Propose an isolated restore test using synthetic or explicitly approved data.
5. Validate data consistency, application readiness, access controls, and elapsed recovery time.
6. Record evidence and gaps; never claim restore success without a completed test.
7. Production restore, overwrite, deletion, and failover remain approval-gated.
